# 이번 생은 축구다

U15 유망주에서 은퇴까지 이어지는 축구선수 커리어 시뮬레이션 게임입니다. 빌드 과정 없이 `index.html` 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 저장 기록은 브라우저의 localStorage에만 남습니다.

## 주요 흐름

- 선수 생성: 이름·등번호·주발·포지션·희망 구단·출신 클럽, 능력치 후보 3명(합 50), 선호 역할, 집중 육성 능력치 2개
- U15 전국대회 3개 → 스카우팅 리포트 → 진로 선택(K리그 유스 입단 테스트 / 해외 유스 / 고교·대학)
- 유스·프로 시즌: 시즌 준비, 특별훈련(커리어 3회 · 시즌당 1회 · 능력치별 1회, 능력치별 미니게임), 시즌 진행, 시즌 결과
- 계약: 첫 계약만 직접 사인하고 이후에는 사인 애니메이션, 계약 만료 시 FA 시장
- 약력: 고교·대학 축구부, 김천 상무·현역 복무는 1년 단위 성장 기록
- 라이벌: U15에서 만난 또래와 시즌마다 기록 비교, 리그 맞대결, 통산 전적
- 국가대표(A매치, 월드컵, 아시안게임, 올림픽), 병역 면제, 클럽 대항전과 개인 수상, 기념 기록 팝업

## PvP 팀 대전

1. 첫 화면의 **PvP 팀 대전**에서 은퇴한 내 선수들로 11명 팀을 꾸립니다(포메이션 4-3-3 / 4-4-2 / 3-5-2). 빈 자리는 OVR 50 유스 선수가 채웁니다.
2. **내 팀 코드 만들기**로 `FL1.`로 시작하는 코드를 복사해 친구에게 보냅니다.
3. 친구는 **상대 팀 코드로 대결하기**에 붙여 넣고 경기를 진행합니다.

같은 두 팀은 누가 실행해도 같은 결과가 나오며, 재대결은 2차전, 3차전으로 이어집니다. 기록은 각자의 브라우저에 저장됩니다.

## 구단 엠블럼

엠블럼 이미지는 저장소에 포함하지 않습니다. SVG 파일을 친구들끼리 따로 주고받은 뒤, 게임 첫 화면의 **구단 엠블럼 → 폴더 불러오기**로 넣으면 배지가 이미지로 바뀝니다. 파일 이름 규칙과 구단별 이름 목록은 [`emblems/README.md`](emblems/README.md)에 있습니다.
