# 구단 엠블럼 이미지

엠블럼 이미지는 저장소에 올리지 않습니다. 이 폴더의 이미지 파일은 `.gitignore`로 커밋에서 빠지니, 친구들끼리 따로 주고받아 주세요.

## 넣는 방법

**방법 1. 게임 화면에서 불러오기 (가장 쉬움)**

1. 게임 첫 화면 아래 **구단 엠블럼** 카드에서 **폴더 불러오기**를 누릅니다.
2. 엠블럼 SVG 파일들이 들어 있는 폴더를 고릅니다. 휴대폰처럼 폴더 선택이 안 되는 기기에서는 **파일 골라 불러오기**로 여러 파일을 한 번에 고르면 됩니다.
3. 적용된 개수가 카드에 표시됩니다. 불러온 엠블럼은 그 브라우저에 저장되어 다음에 열어도 유지됩니다.

**방법 2. 폴더째 넣기**

`index.html`과 같은 위치의 `emblems/` 폴더에 SVG 파일을 넣고 `index.html`을 열면 됩니다.

## 파일 규칙

- 형식: `.svg`
- 파일 이름은 아래 표의 영문 이름(`arsenal.svg`)이나 구단 이름(`아스날.svg`) 둘 다 됩니다. 대소문자, 띄어쓰기, `-`·`_`는 구분하지 않습니다(방법 1 기준). 방법 2는 영문 이름만 됩니다.
- 이름이 맞지 않는 파일은 불러올 때 알려 줍니다. 엠블럼이 없는 구단은 두 글자 배지로 표시됩니다.
